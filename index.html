THỰC HÀNH NHÚNG CSS VÀO HTML

Phần 1: Inline Style

Đoạn văn này được thay đổi màu sắc bằng cách sử dụng Inline Style (thuộc tính style trực tiếp trong thẻ).

Phần 2: Internal Style

Đoạn văn này được thay đổi màu sắc bằng cách sử dụng Internal Style (viết trong thẻ <style> ở <head>).

Phần 3: External Style

Đoạn văn này được thay đổi màu sắc bằng cách sử dụng External Style (liên kết với file style.css riêng biệt).
